Privacy Policy

This application is a personal rclone configuration used only by its owner.

  • It accesses Google Drive only on the owner's own computer, to copy the owner's own files.
  • No data is collected, stored on any server, shared with, or sold to third parties.
  • OAuth tokens stay in the local rclone configuration file and can be revoked at any time at myaccount.google.com/permissions.

Use of Google user data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
